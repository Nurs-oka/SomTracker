# SomTracker — учёт личных расходов в сомах

Midterm project for Mobile Application Development.

## Возможности
- Три раздела: расходы, доходы и общий журнал операций.
- Быстрое добавление расходов и доходов по категориям с суммой и комментарием.
- Создание собственных категорий расходов и доходов.
- Баланс рассчитывается как доходы минус расходы.
- Редактирование и удаление операций из журнала.
- Категории расходов: Еда, Транспорт, Учёба, Дом, Здоровье, Развлечения, Прочее.
- Категории доходов: Зарплата, Стипендия, Подработка, Подарок, Прочее.
- REST API на Node.js + Express.
- Управление состоянием через Flutter BLoC и Equatable.

## Структура
- `backend/` — REST API.
- `mobile_app/lib/data/` — модели и репозиторий.
- `mobile_app/lib/logic/bloc/` — события, состояния и бизнес-логика.
- `mobile_app/lib/presentation/` — экран и виджеты.

## Требования
Установите Node.js и Flutter SDK. Для запуска на компьютере подойдёт Edge или Chrome.

## Запуск на Windows PowerShell
Из корневой папки проекта выполните:
```powershell
cd backend
npm install
cd ..\mobile_app
flutter pub get
flutter build web
cd ..\backend
npm start
```

Backend будет обслуживать и приложение, и API. На компьютере откройте `http://localhost:3000`. Проверка API: `http://localhost:3000/api/health`.

## Запуск на телефоне через Wi-Fi
1. Подключите телефон и компьютер к одной Wi-Fi сети.
2. Соберите web-версию командой `flutter build web` из папки `mobile_app`.
3. Запустите backend командой `npm start` из папки `backend`.
4. Узнайте локальный IPv4-адрес компьютера командой `ipconfig` (например, `192.168.1.25`).
5. Откройте на телефоне `http://192.168.1.25:3000`, заменив адрес примером из `ipconfig`.

Если Windows спросит разрешение для Node.js, разрешите доступ в частных сетях. Если страница не открывается, проверьте, что брандмауэр пропускает порт `3000`.

## Запуск на Android Emulator
Backend запускается на компьютере, а приложение в эмуляторе обращается к нему через `10.0.2.2:3000`.
Для физического Android-устройства замените адрес в `expense_repository.dart` на локальный IP компьютера в той же Wi-Fi сети. Для Android также может понадобиться разрешить HTTP-трафик в debug-конфигурации.

## API
- `GET /api/transactions` — получить доходы и расходы.
- `POST /api/transactions` — добавить операцию (`type`, `title`, `amount`, `category`, `comment`).
- `PATCH /api/transactions/:id` — изменить операцию.
- `DELETE /api/transactions/:id` — удалить операцию.
- `GET /api/categories` и `POST /api/categories` — получить и добавить категории расходов/доходов.
- `GET /api/health` — проверить работу сервера.

## Примечание
Данные операций и пользовательские категории хранятся в памяти Node.js. После перезапуска backend они сбросятся к демонстрационному набору и стандартным категориям. Для постоянного хранения потребуется база данных.
